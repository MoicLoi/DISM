# DISM 1.5.0

**Dynamic Intelligent Schedule Manager** —
一个本地优先的个人语义状态与自适应调度引擎。

这一版的重点不是"功能变多"，而是**整条链路第一次能被完整验证**：
从语义模型、调度决策、决策历史落盘，到三端 UI 真正跑起来。

---

## 这个版本能做什么

```text
日常项        实体 / 关系 / 证据组成的语义模型
动态调度      按当前状态评估"现在该做什么"，并给出理由
决策历史      记录决策**何时改变**，而不是每次加载都写一条
注意力        需要人处理的事情单列出来
日历导入      .ics 直接导入，三端各有自己的取文件方式
```

四个平台目标：

```text
桌面        可安装运行（本版验证到"启动并响应"）
Web (js)    编译 + 浏览器测试通过
Web (wasm)  编译 + 浏览器测试通过
Android     编译通过，APK 可安装
```

## 安装 / 使用

### 桌面（Windows x64）

```powershell
# 解压后直接运行（exe 在解压目录根部）
dism-1.5.0-desktop-windows-x64.zip
  └── me.moiclathy.dism.exe
```

数据落在 `~\.dism\`（`dism.db` 与 `calendar.ics`）。
删掉该目录即可回到初始状态。

> 这一份是**从发布包里解压出来、真的启动过**的：窗口标题 `DISM`、
> 日志到 `DISM.BOOTSTRAP.READY`、`dism.db` 被写入。
> 不是"构建成功所以应该能跑"。

### Web

`dism-1.5.0-web-js.zip` 或 `dism-1.5.0-web-wasm.zip` 解压后是纯静态站点，
用任何静态服务器托管即可（例如 `python -m http.server 8080`）。

> Web 端数据存在浏览器 `localStorage`：日历与决策历史都能跨刷新存活，
> 但不同浏览器之间不共享，也没有导入导出。

### Android

`dism-1.5.0-debug.apk` 是 **debug** 包，未使用发布证书签名，
安装时系统会提示"未知来源"。这是有意的：没有证书就不假装签过。

## 打包过程中修掉的两个问题

发布不是"构建通过就发"，这两条都是打包阶段才暴露的：

```text
1. 桌面安装包缺 java.sql 模块
   jpackage 用 jdeps 猜运行时模块，jdeps 看不到反射；
   SQLDelight 通过 java.sql.DriverManager 建连接，于是打出闪退的包。
   修法：nativeDistributions { modules("java.sql", "java.naming", "jdk.unsupported") }
   这个洞不可能被 :app:desktopApp:run 发现——那条路用完整 JDK。

2. 依赖校验清单有 31 个 classpath 条目缺失
   平时被 configuration cache 掩盖：缓存命中时解析结果直接反序列化，
   校验根本不执行。改了 build 脚本、缓存失效后才突然
   "Dependency verification failed for configuration 'classpath'"。
   修法：在完整任务集上重写 verification-metadata.xml，
   并加了一条冷启动校验（--stop 之后 help --no-configuration-cache）。
```

## 已知行为，不是 bug

```text
存储失败会抛    本地存储不可用时不会静默退化成内存存储——
                用户以为存住了、其实没存，比直接报错更糟
历史上限        决策历史按"变了才写"记录，因此是变更日志而非轮询快照
导航只列已实现  未实现的目的地不出现在导航里，而不是点进去看"未实现"
Web 无跨设备    没有账号、没有同步，这是本地优先的代价
```

## 校验下载

Release 里那份清单叫 `dism-1.5.0-SHA256SUMS.txt`（前缀只是为了避免附件重名，
里面记的仍是相对包根目录的路径）：

```powershell
Get-FileHash .\dism-1.5.0-desktop-windows-x64.zip -Algorithm SHA256
# 与 dism-1.5.0-SHA256SUMS.txt 中对应行比对
```

Linux / macOS 上可以直接整包校验：

```bash
sha256sum -c dism-1.5.0-SHA256SUMS.txt
```
